## 摘要
视觉-语言模型（VLMs）展现出强大的零样本能力，使其成为跨多样任务持续学习的吸引力方案。然而，在持续适应过程中，灾难性遗忘和零样本性能退化同时发生，严重影响性能。本文提出TASSO，一种高效保持潜在空间几何结构同时确保网络可塑性的新范式。我们通过两种互补技术实现：子空间学习和几何感知知识蒸馏。具体而言，首先学习一系列任务特定的低秩投影器，在优化交叉熵之前用其投影潜在表示。其次，采用基于测地线距离的损失从先前任务模型中蒸馏知识，同时有效保持潜在空间几何结构。这些设计选择不仅避免沿全嵌入维度进行不必要的参数更新，还通过聚焦于任务特定流形来改善学习。此外，几何感知蒸馏提供强正则化，显著减少持续学习序列中的灾难性遗忘和零样本退化。在CLIP视觉语言模型的multi-domain任务增量学习和类增量学习基准上的实验结果表明，在缓解遗忘和保持零样本能力方面，该方法明显优于现有最先进方法。

## Abstract
Vision-Language Models (VLMs) exhibit strong zero-shot capabilities, making them an attractive solution for continual learning across diverse tasks. However, during continual adaptation, both catastrophic forgetting and zero-shot degradation occur, severely degrading performance. In this paper, we introduce TASSO, a new paradigm that efficiently preserves the latent space geometry while ensuring network plasticity. We achieve this with two complementary techniques: subspace learning and geometry-aware knowledge distillation. Specifically, we first learn a sequence of task-specific low-rank projectors, which we use to project the latent representations before optimizing cross-entropy. Secondly, we employ a geodesic-distance-based loss that distills knowledge from the previous-task model while effectively preserving the latent space geometry. These design choices not only avoid unnecessary parameter updates along the full embedding dimensions but also improve learning by focusing on task-specific manifolds. Moreover, the geometry-aware distillation provides strong regularization and significantly reduces both catastrophic forgetting and zero-shot degradation throughout the continual learning sequence. Experimental results with the CLIP vision language model in the multi-domain task incremental and class incremental learning benchmarks demonstrate clear improvements over state-of-the-art methods in mitigating forgetting and preserving zero-shot capabilities.

## 1. 论文核心问题与研究动机

- **背景**：视觉-语言模型（VLMs），如 CLIP、BLIP、ALIGN 和 Flamingo，在零样本任务上表现优异，广泛应用于计算机视觉与自然语言处理的交叉领域。然而，在实际部署（如具身智能、自动驾驶、机器人）中，静态的通用知识难以满足持续变化的任务需求，因此需要能够**持续学习新概念**的 VLM。
- **核心问题**：在 VLMs 上进行持续学习时，面临两个关键挑战：
  1. **灾难性遗忘（Catastrophic Forgetting）**：学习新任务会导致模型在旧任务上的性能显著下降；
  2. **零样本退化（Zero-Shot Degradation）**：学习某个任务后，模型在**未来未见任务**上的零样本能力也会大幅退化，这是 VLM 持续学习场景特有的挑战。
- **研究核心**：在可塑性（学习新知识）与稳定性（保留旧知识与零样本能力）之间取得平衡，同时避免引入过多额外参数或复杂架构。

## 2. 方法论：核心思想与关键技术

- **总体架构**：TASSO 仅微调 CLIP 的视觉编码器，文本编码器保持冻结。在每个增量任务上，总损失由三部分构成，最终目标为：

  \[
  L = L_{CE} + \alpha L_{sub} + \beta L_{KD}
  \]

  其中 \(\alpha=0.5\)，\(\beta=3\)。

### 2.1 子空间学习（Subspace Learning）——恢复网络可塑性

- **动机**：现有知识蒸馏策略在整个高维潜空间上均匀施加正则化，容易压制网络的学习能力（可塑性下降）。
- **核心思想**：将当前任务的学习限制在一个**低秩子空间**内，仅在该子空间中进行灵活的适应与优化，而其余流形区域尽量保持不变，从机制上降低任务目标与蒸馏正则之间的冲突。
- **技术细节**：
  - 每个任务 \(k\) 学习一个低秩投影器 \(U_k \in \mathbb{R}^{d \times r}\)（实验中 \(r = 144\)，远小于维度 \(d\)）；
  - 通过 QR 分解对随机初始化的代理矩阵 \(A\) 进行重参数化，保证 \(U_k^\top U_k = I\)（正交基）；
  - 将嵌入分解为任务特定部分 \(f_\parallel = U_k U_k^\top f\) 和任务无关部分 \(f_\perp = f - f_\parallel\)；
  - 子空间损失 \(L_{sub}\) 为投影后特征与文本嵌入的交叉熵（见公式 2–3）；
  - **重要设计**：低秩投影只在训练阶段使用，推理时去掉，因此不增加推理成本，MTIL/MCIL 均可无缝切换。

### 2.2 测地线距离知识蒸馏（Geometry-Aware Knowledge Distillation）——强化稳定性

- **动机**：CLIP 的归一化嵌入分布在高维球面上，L2/余弦距离未能完全贴合该流形的内在几何结构；而测地线距离（球面弧长）更符合 CLIP 潜空间的拓扑特性，有助于保持零样本能力。
- **技术细节**：
  - 测地线距离公式：\( L_{geo} = \cos^{-1}(\langle g_k(x), g_{k-1}(x) \rangle) \)；
  - 将蒸馏损失分解到**任务特定子空间**与**任务无关子空间**上分别计算，即：

  \[
  L_{KD} = \frac{1}{N} \sum_{j=1}^{N} \left[ L_{geo}(f^{k}_{\parallel,j}, f^{k-1}_{\parallel,j}) + L_{geo}(f^{k}_{\perp,j}, f^{k-1}_{\perp,j}) \right]
  \]

  - 该分解方式比直接在原始向量上计算测地线距离效果更好（精度相近，但遗忘和零样本退化分别降低约 33% 和 39%，见附录 B.3）。

### 2.3 与现有方法的差异

- 相比 SnD（需要两个教师模型：预训练模型 + 上一任务模型），TASSO **仅需上一任务的单一教师模型**，即可同时缓解灾难性遗忘与零样本退化；
- 相比 MoE-Adapters 等方法，TASSO **不需要额外添加适配器模块**，参数开销更低，架构更简洁。

## 6. 主要结论与发现

- **MTIL 设置**：TASSO 平均准确率 **85.89%**，较最佳竞争者 SnD（84.92%）提升约 1%；灾难性遗忘仅 **0.67%**（SnD 为 1.20%）；零样本退化仅 **0.47%**（SnD 为 1.96%），下降约 4 倍。
