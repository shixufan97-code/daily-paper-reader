## 摘要
视觉语言模型（VLMs）擅长描述可见的场景内容，但在推理动态多智能体交互方面存在困难，因为这些交互中的动作语义依赖于协调的角色和时空依赖关系。我们将这种能力形式化为**多智能体战术推理**，并引入**DoublesEval**，一个利用专业双打羽毛球作为结构上可处理的测试平台的诊断性评估框架。DoublesEval采用基于关键时刻的协议，将回合分解为战术上重要的瞬间，并在四个可解释维度上探测模型：原子识别、段内复合理解、跨段因果推理和高层战术抽象。这种设计能够隔离推理失败的具体位置，而不仅仅是衡量答案的正确性。针对观察到的失败模式，我们提出了**TacticCheck**，一个轻量级的约束引导测试时一致性检查器，它利用模型自身较低层次的战术预测对候选答案进行重新排序，在推理时无需参数更新或真实标签。通过零样本协议，对60个精选回合（产生约9.6K个结构化实例）评估四个代表性的开源视觉语言模型，我们发现模型在所有诊断级别上仍然表现薄弱，尤其在空间状态、交互绑定和终端证据方面存在明显的瓶颈。TacticCheck在所有评估模型上均带来一致的性能提升，但距离稳健的战术推理仍有很大差距。这些结果凸显了为下一代视觉语言模型设计结构化、交互感知评估范式的必要性。源代码可在我们的GitHub仓库中获取。

## Abstract
Visual Language Models (VLMs) excel at describing visible scene content but struggle to reason about dynamic multi-agent interactions, where action semantics depend on coordinated roles and spatial-temporal dependencies. We formalize this capability as \textbf{multi-agent tactical reasoning} and introduce \textbf{DoublesEval}, a diagnostic evaluation framework that leverages professional doubles badminton as a structurally tractable testbed. DoublesEval employs a key-moment-based protocol that decomposes rallies into tactically salient instants and probes models across four interpretable dimensions: atomic recognition, intra-segment composite understanding, cross-segment causal reasoning, and high-level tactical abstraction. This design isolates \emph{where} reasoning fails, rather than merely measuring answer correctness. To address observed failure modes, we propose \textbf{TacticCheck}, a lightweight constraint-guided test-time consistency checker that reranks candidate answers using the model's own lower-level tactical predictions, requiring no parameter updates or ground-truth labels at inference time. Evaluating four representative open-source VLMs on 60 curated rallies (yielding $\sim$9.6K structured instances) via a zero-shot protocol, we find that models remain weak across all diagnostic levels, with especially clear bottlenecks in spatial state, interaction binding, and terminal evidence. TacticCheck delivers consistent gains across all evaluated models, while still leaving a substantial gap to robust tactical reasoning. These results highlight the need for structured, interaction-aware evaluation paradigms for next-generation VLMs. The source code is available in \href{https://github.com/Chengjt1999/DoublesEval}{\textcolor{blue}{our GitHub repository}}.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有视觉语言模型（VLMs）在静态内容描述、单智能体动作识别和全局事件分类上表现优秀，但面对多智能体动态交互时能力显著不足——动作语义依赖于角色协调与时空依赖，这种能力被作者形式化为**多智能体战术推理**（multi-agent tactical reasoning）。已有视频评测基准（如TempCompass、Video-MME）大多针对单智能体轨迹或全局事件，无法暴露角色归属、空间覆盖、跨事件因果等系统性失败。
- **整体含义**：作者选择**职业双打羽毛球**作为结构上可处理、语义上丰富的测试床，提出 **DoublesEval** 诊断框架，将战术推理拆分为四个可解释层级，精确定位模型在哪一环节失败；并据此提出轻量级测试时一致性检查器 **TacticCheck**。整体研究强调：当前 VLM 的薄弱点不在“看见”，而在“将可见证据绑定为多智能体战术链条”。

## 2. 论文提出的方法论

- **核心思想**：以“得分瞬间（scoring moment）”为锚点，将每一回合分解为战术关键瞬间序列，并为每个瞬间设计分层诊断问题。模型全程观看完整回合视频，但问题与标注仅锚定得分窗口内（最后得分拍及前3-5拍）的战术状态，从而检验“关键时刻理解”而非全局概括。
- **四个诊断维度**：
  - **L1 原子识别**：单时刻、单字段视觉 grounding，如球员位置、场地分区、击球类型。
  - **L2 段内复合理解**：局部片段内多视觉线索联合绑定，如“空间关系+角色+动作状态”。
  - **L3 跨段因果推理**：跨≥2个关键时刻的因果链建模，如“前一拍决策导致后一拍走位”。
  - **L4 高层战术抽象**：对较长回合模式进行归纳与概括，如轮转、覆盖分工、攻防转换。
- **实例设计**：每个维度构造配对问题——**SCQ（单选题）** 与 **SAQ（简答题）**，共约9,600个实例。SCQ有4个选项（1个正确+3个基于常见失败模式构造的干扰项）；SAQ则要求模型给出自由文本解释，再由 GPT-5 标签映射裁判对齐到标准化标签空间。
- **TacticCheck 测试时一致性检查**：
  - 先抽取模型自身对 L1 字段的预测，构成战术清单 `z = {s_near, s_far, b_near, b_far, c, r}`（近/远队空间状态、交互线索、结果归因、得分证据）。
  - 对高层单选题的每个候选选项，映射为战术签名，计算与清单的惩罚项：`Penalty(oi, z) = λs·1[φs(oi)≁zs] + λb·1[φb(oi)≁zb] + λc·1[φc(oi)≁zc] + λr·1[φr(oi)≁zr]`。
  - 最终选择为 `o_hat = argmax[BaseScore(oi) − Penalty(oi, z)]`；若没有明显更优选项则保守保留原答案。
  - 该方法无需参数更新、无需真实标签，仅利用模型自身低层预测进行重排。

## 3. 实验设计

- **数据来源**：从 BWF 世界巡回赛 Super 750 / Super 1000 级别中选取4场比赛（2场男双、1场女双、1场混双），均为官方1080p直播视频。筛选出60个回合，平均时长约10秒，平均12.4拍/回合。

## 6. 论文的主要结论与发现

- **零样本战术推理整体薄弱**：四个模型总体准确率仅在 28.65%–32.35% 之间，且L1原子识别也不饱和（最高37.5%），说明问题不仅在高阶推理。
- **瓶颈集中在结构化关系而非基本感知**：时间阶段识别相对较好（约45–57%），但空间状态（约22–28%）、交互绑定（约21–24%）和得分细节（约24–28%）持续低落；L1字段中“stroke pattern”最难。
- **因果链脆弱**：L3跨段因果推理准确率最低之一（约23–29%），原因可追溯到 L1 阶段对终局击球与交互关系的错误绑定。
- **TacticCheck 一致提升但非治愈**：在SCQ上带来 +7.13～+8.20 个百分点的提升，但所有模型仍低于40%，且存在一定比例的正确答案被改错（R→W 约5%）。作者明确将 TacticCheck 定位为“诊断干预”而非完整解决方案。
- **对后续研究的启示**：下一代 VLM 需要更强的交互建模与结构化关系推理能力，而不只是更大的视觉编码器或更精细的提示。

## 7. 优点

- **问题形式化清晰**：首次将“多智能体战术推理”作为独立评估目标，并给出四层可解释诊断维度，使失败定位从“对错”升级为“在哪断链”。
- **测试床选择巧妙**：双打羽毛球仅4人、场地严格受限、角色转换频繁、因果链密集，既可通过穷举标注保证质量，又具备足够的战术深度。
- **标注规范**：两级专家标注+国家级运动员审计，并用相对角色描述（如“发球方后场球员”）取代姓名，避免身份捷径。
- **TacticCheck 轻量且实用**：无需重训、无需真实标签，仅利用模型自身低层预测进行重排，模拟教练复核逻辑，可方便地集成到现有测试流程中。
- **实验分析粒度细**：不仅报告总体准确率，还提供了能力级和字段级诊断，为社区定位模型弱点提供了直接参考。

## 8. 不足与局限

- **数据规模与多样性受限**：仅4场比赛60个回合，球员风格与战术类型覆盖有限；作者虽声明是“诊断套件”的刻意取舍，但仍影响结论的泛化性。
- **模型范围不够广**：只评测了4个开源VLM，未包含闭源模型（如GPT-4V/5等），也未针对不同视频编码架构进行系统比较。
- **TacticCheck 依赖模型自身低层预测**：若L1清单本身错误，重排会传播并放大错误；实验中也观察到右→错翻转，说明其收益有上限。
- **标签映射裁判可能引入偏差**：GPT-5作为裁判进行语义映射，虽然人工复核子集证明了较高一致性（κ=0.81），但在高层战术抽象维度一致性最低（κ=0.73），说明语义对齐本身存在主观性。
- **SAQ评估的信息损失**：将自由文本强制映射到离散标签，可能丢失合理但表述不同的正确推理；生成的“理由”没有被直接质量评估。
- **算力细节缺失**：未报告GPU型号、数量、推理时间等资源指标，不利于复现与成本评估。
