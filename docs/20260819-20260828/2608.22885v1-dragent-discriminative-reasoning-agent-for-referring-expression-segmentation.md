## 摘要
指代表达式分割（Referring Expression Segmentation, RES）旨在为语言表达式所指定的对象生成像素级掩码。近年来基于多模态大语言模型（MLLMs）的方法通常依赖一次性坐标预测进行视觉定位，这种方法将连续的空间位置序列化为离散的文本标记，可能导致定位偏差和对齐误差。为解决这些问题，我们提出了DRAgent，一种面向RES的MLLM驱动的判别式推理（Discriminative Reasoning, DR）框架。DRAgent无需MLLM生成定位坐标，而是首先构建一个由检测器生成的候选空间，然后将MLLM用作视觉语义目标判别器。具体而言，MLLM通过两阶段DR机制在潜在干扰物中进行可靠的目标选择，该机制首先筛选高召回率候选，然后进行实例级验证。选定的目标框随后作为空间提示输入到基础分割模型中，以生成最终的像素级掩码。此外，我们构建了一个自一致性过滤的推理链数据流水线，用于基于LoRA的微调，为增强MLLM的判别式推理能力提供更可靠的监督。实验表明，DRAgent在RefCOCO、RefCOCO+和RefCOCOg上取得了具有竞争力的性能。

## Abstract
Referring Expression Segmentation (RES) aims to generate a pixel-level mask for the object specified by a language expression. Recent methods based on multimodal large language models (MLLMs) often rely on one-pass coordinate prediction for visual localization, which serializes continuous spatial locations as discrete text tokens and may lead to localization bias and alignment errors. To address these issues, we propose DRAgent, an MLLM-driven discriminative reasoning (DR) framework for RES. Instead of requiring the MLLM to generate localization coordinates, DRAgent first constructs a detector-generated candidate space and then uses the MLLM as a visual-semantic target discriminator. Specifically, the MLLM performs reliable target selection among potential distractors through a two-stage DR mechanism, which first screens high-recall candidates and then performs instance-wise verification. The selected target box is subsequently used as a spatial prompt for a foundation segmentation model to produce the final pixel-level mask. Furthermore, we construct a self-consistency-filtered reasoning-chain data pipeline for LoRA-based fine-tuning, providing more reliable supervision for enhancing the MLLM's discriminative reasoning capability. Experiments demonstrate that DRAgent achieves competitive performance on RefCOCO, RefCOCO+, and RefCOCOg.

  - 定位偏差（localization bias）
  - 对齐误差（alignment error）

- **论文主张**：不要将视觉定位视为生成式坐标预测，而是将其**重构为判别式目标选择**——由开放集检测器提供候选空间，MLLM 作为判别器从中挑选最佳匹配目标，从而规避坐标离散化带来的问题。

## 2. 方法论

### 总体框架
DRAgent 将 RES 分解为三级流程：

1. **候选目标检测**：从查询 Q 中抽取目标类别，使用开放集检测器（Grounding DINO）生成高召回率候选框集合 O。
2. **判别式目标选择**：MLLM 作为判别器，通过两阶段 DR 机制从候选集合中选出与查询最匹配的目标框。
3. **像素级分割**：将选中目标框作为空间提示输入 SAM，生成最终掩码。

整体流程可形式化为：

\[
M = f_{\text{seg}}\left(I,\ \Phi_{\text{select}}\left(I, Q, g_{\text{det}}(I, \text{LLM}(Q))\right)\right)
\]

### 两阶段判别式推理（DR）
- **第一阶段：候选级初步筛选**
  - 使用 Set-of-Mark（SoM）在图像上标注候选框。
  - MLLM 依据查询从所有候选中选出 top-K 最可能目标。
  - 为了保留召回率，将与该 top-K 框 IoU 超过阈值 γ 的候选也纳入集合，得到第二阶段的候选集 \(O_{\text{top}}\)。
- **第二阶段：实例级验证**
  - 对 \(O_{\text{top}}\) 中每个候选，单独渲染 SoM 框，并给出结构化询问：“红色框是否紧密包围了描述 {Q} 的对象？回答 yes 或 no。”
  - 为了获得更稳定的判别信号，不直接取最大概率 token，而是定义验证分数：

    \[
    S_i = \frac{\exp(z_{i,V_{\text{pos}}})}{\exp(z_{i,V_{\text{pos}}}) + \exp(z_{i,V_{\text{neg}}})}
    \]

    其中 \(z_{i,V_{\text{pos}}}\) 和 \(z_{i,V_{\text{neg}}}\) 分别是“Yes/yes/YES”和“No/no/NO”两类 token 的平均 logits。
  - 选择验证分数最高的候选作为目标，即 \(t = \arg\max_{i \in O_{\text{top}}} S_i\)。

### 数据流水线与训练
- **自一致性过滤的推理链数据管道**：
  - **阶段 1（生成）**：将目标区域（可能是真目标或硬负样本）用 SoM 渲染，输入 MLLM，要求输出结构化 JSON：{"reason": "...", "description": "...", "answer": "Yes/No"}，得到推理链 \(R_1\)、描述 \(D_1\) 和答案 \(A_1\)。
  - **阶段 2（自验证）**：用描述 \(D_1\) 构造新查询，再次输入 MLLM，得到推理链 \(R_2\) 和答案 \(A_2\)。
  - **保留条件**：仅当 \(A_1\) 与真实标签一致，且 \(A_2\) 对重建描述给出“Yes”时，该推理链才被保留用于训练，否则丢弃。
- **微调**：使用过滤后的数据对 Qwen3-VL-8B-Instruct 进行 LoRA 监督微调，降低训练成本并增强判别能力。

## 6. 主要结论

- DRAgent 通过将 MLLM 的角色从“坐标生成器”转变为“判别式目标选择器”，有效避免了坐标离散化带来的定位偏差和对齐误差。
- 两阶段 DR 机制（候选筛选 + 实例级验证）显著提升了目标选择的稳定性与准确性。
- 自一致性过滤的推理链数据为 LoRA 微调提供了更可靠的监督信号，优于无 CoT 或原始 CoT 数据。
- 在 RefCOCOg 上取得了最佳结果（val(U) 76.78%，test(U) 77.54%），在 RefCOCO 和 RefCOCO+ 上也表现出竞争力，验证了判别式推理范式在细粒度定位任务中的有效性。

## 7. 优点

- **问题重构创新**：将 RES 中的视觉定位从生成式坐标预测改为判别式候选选择，思路新颖，直击现有方法的痛点。
- **模块化设计**：检测器、MLLM、分割模型可灵活替换，具备良好的可扩展性。
- **两阶段级联推理**：先粗筛再细验，降低了单次决策的难度，符合人类视觉注意机制。
- **数据质量保障**：通过自一致性过滤剔除仅“语言通顺但视觉不符”的推理链，提高了监督信号可靠性。
- **训练高效**：仅用 6K 样本 + LoRA 微调，即可取得竞争力强的结果，说明方法具有较好的数据效率。

## 8. 不足与局限

- **依赖检测器质量**：若 Grounding DINO 漏检目标，后续判别与分割将无法挽回，整体性能受上游候选空间限制。
- **训练数据覆盖不足**：仅使用 RefCOCO 的 6K 样本进行训练，未在 RefCOCO+、RefCOCOg 的训练集上微调，可能低估模型在这些基准上的潜力。
