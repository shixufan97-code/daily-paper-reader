## 摘要
我们通过重新审视聚类这一机器学习中最经典的方法之一，来探究视觉主干网络中的令牌混合器。一个有效的令牌混合器是现代视觉主干网络（如视觉Transformer）的基础组件，用于促进图像块之间的信息交换。主流的令牌混合器依赖于卷积、注意力、MLP或其混合形式，主要聚焦于在精度与计算成本之间进行权衡。然而，这些方法的一个显著缺点是它们的黑盒性质；其编码过程不透明且缺乏可解释性。与这些不透明的设计不同，我们引入了ClusterMixer，一种透明的令牌混合器，它基于聚类范式，并且在设计上具有可解释性。ClusterMixer通过层次聚类机制显式地公式化令牌混合过程。为了建模视觉数据中固有的自然树状关系，聚类在双曲空间中进行，该空间非常适合以低失真嵌入层次结构。基于这一创新，我们提出了HCFormer，一种新的主干架构，它将ClusterMixer与一系列精心设计的聚类策略相结合，以确保在各种任务中的稳健性能。大量实验表明，HCFormer在包括图像分类、目标检测、实例分割和语义分割在内的各种任务中始终优于其对应方法。考虑到其透明性和有效性，我们希望HCFormer能够促进向可解释主干网络的范式转变。

## Abstract
We investigate the token mixer in vision backbones by revisiting clustering, one of the most classic approaches in machine learning. An effective token mixer is a fundamental component of modern vision backbones like vision Transformers, facilitating information exchange between image patches. Mainstream token mixers, which rely on convolution, attention, MLP, or their hybrids, primarily focus on navigating the trade-off between accuracy and computational cost. However, a significant drawback of these methods is their black-box nature; their encoding process is opaque and lacks interpretability. Diverging from these opaque designs, we introduce ClusterMixer, a transparent token mixer that is grounded in a clustering paradigm and interpretable by design. ClusterMixer explicitly formulates the token mixing process through a hierarchical clustering mechanism. To model the natural, tree-like relationships inherent in visual data, the clustering is performed in hyperbolic space, which is well-suited for embedding hierarchies with low distortion. Building on this innovation, we present HCFormer, a new backbone architecture that integrates ClusterMixer with a series of meticulously designed clustering strategies to ensure robust performance across tasks. Extensive experiments demonstrate that HCFormer consistently outperforms its counterparts across diverse tasks, including image classification, object detection, instance segmentation, and semantic segmentation. Considering its transparency and efficacy, we hope HCFormer can facilitate a paradigm shift toward interpretable backbones.

### 2. 论文提出的方法论

- **核心思想**：以聚类算法替代传统 token mixer（如注意力、卷积、MLP），通过显式地将 token 进行分组和聚合，实现信息交换，同时天然具备可解释性。
- **ClusterMixer（聚类混合器）**——包含三个步骤：
  1. **中心估计**：基于 token 特征嵌入，通过**平均池化**对邻近 patches 进行聚类中心估计，无需额外可学习参数，复杂度与序列长度呈线性关系。
  2. **聚类分配**：采用 **soft clustering（软聚类）**，即每个 token 以一定概率分配给多个聚类中心。分配概率根据特征相似度（含可学习的相似度缩放因子 α 和相对位置偏置 B）计算，公式为：
     - \( a_i = \text{Softmax}(\alpha \cdot D(x_i, c_j) + b_{i,j}) \)
  3. **Token Mixing**：基于分配矩阵进行特征聚合与传播，先由数据点向聚类中心聚合上下文特征，再将该特征传播回各数据点，通过一个全连接层更新 token 表示。
- **层次聚类（Hierarchical Clustering）策略**：
  - **Patch 级聚类（patch-level）**：在局部窗口内进行，处理细粒度特征；
  - **Window 级聚类（window-level）**：以每个窗口为数据点，进行全局聚类，捕获上下文信息；
  - 该双层级设计将 token mixer 的复杂度从二次方降至线性，同时兼顾局部细节与全局语义。
- **双曲层次聚类**：
  - **动机**：欧几里得空间是"平坦"的，难以低失真地建模视觉数据中固有的**树状层次关系**；双曲几何作为树的连续模拟，能更好地编码复杂、抽象的语义结构。
  - **技术路径**：在 **Lorentz 模型**下定义双曲空间，使用**指数映射（exponential map）** 将欧几里得向量投影到双曲流形，并利用 **Lorentzian distance** 计算双曲空间中的相似度。
  - **双几何协同**：**Patch 级聚类使用欧几里得几何**（高效、稳定、适合局部平面结构）；**Window 级聚类使用双曲几何**（适合建模全局层次关系）。两者并行计算后再融合，兼顾效率与表达力。

### 6. 主要结论与发现

- **性能优势显著**：
  - 图像分类：HCFormer-Medium 达到 82.4% Top-1，超过 Swin-Tiny（81.3%）1.1%，超过 ResNet-50（79.8%）2.6%；相比聚类式 CoC 和 FEC，各规模下提升 1.2%～3.3% 和 0.3%～2.4%；

  - 目标检测/实例分割：HCFormer-Medium 在 Mask R-CNN 下取得 40.9% AP box / 37.6% AP mask，优于大多数同规模基线。
- **可解释性落地**：聚类可视化表明，模型学习到的聚类结构能够反映图像中真实的语义/空间关系，说明聚类式 token mixer 确实提供了人类可理解的编码过程。
- **技术发现**：
  - 层次聚类优于 Swin 式移位窗口机制（73.4% vs 72.7%）；
  - 双曲距离显著优于欧几里得距离用于窗口级聚类（75.1% vs 73.4%）；
  - 曲率变化对性能影响很小（模型对曲率超参稳健）；
  - 各个设计组件（层次聚类、双曲几何、相对位置）具备互补性，缺一不可。

### 7. 优点

- **可解释性优先**：ClusterMixer 不依赖黑盒注意力，而是通过显式聚类过程进行 token 混合，让模型的中间表征具有语义上的可读性，是"透明视觉骨干"方向的有力探索。
- **创新的双几何设计**：提出在欧几里得空间（局部、细粒度）与双曲空间（全局、层次化）中分别执行聚类的混合几何架构，兼顾效率与表达能力，思路新颖。
- **计算效率**：分层聚类策略将 token mixer 的复杂性从 O(N²) 降到 O(N)，对高分辨率/长序列的视觉任务友好，且吞吐量优于同量级聚类方法。
- **系统全面**：从方法设计、模型架构到大量实验验证，形成完整闭环，不仅展示了性能提升，还从消融实验和可视化多个维度验证了设计决策的合理性，说服力强。
