## 摘要
视觉-语言模型（VLM）在各种视觉-语言任务上表现出色，但基于Transformer的视觉编码器会将图像分割成固定分辨率的子图像，从而损害轻量级VLM中的物体完整性。现有方法仅关注视觉模态，无法动态保持与提示相关区域的完整性，限制了性能。在这项工作中，我们观察到跨模态注意力的早期层图像-文本熵与答案基础质量和任务准确性密切相关。基于这一发现，我们提出了\textbf{ENCORE}，一个包含两个组件的基于熵的框架：在推理时，\textbf{基于熵的裁剪策略}（ECS）评估少量候选裁剪区域，并选择熵最小的一个，从而保留与提示相关的连续区域。在训练时，\textbf{熵正则化训练}（ERT）通过一个熵项增强下一个词元预测，该熵项会锐化对关键视觉词元的注意力，同时降低不相关词元的权重。在十个VQA基准上的实验表明，仅微调0.14\%的参数，ENCORE平均准确率提升1.43\%，并在近期2B参数VLM中达到最先进的性能。我们的代码发布在https://github.com/baokou-fw2/ENCORE。

## Abstract
Vision-Language Models (VLMs) perform well on diverse vision-language tasks, but transformer-based visual encoders split images into fixed-resolution sub-images, compromising object integrity in lightweight VLMs. Existing methods only focus on the visual modality and fail to dynamically preserve the integrity of prompt-relevant regions, limiting performance. In this work, we observe that the early-layer image-text entropy of cross-modal attention strongly correlates with answer grounding quality and task accuracy. Building on this finding, we propose \textbf{ENCORE}, an entropy-guided framework with two components: At inference, an \textbf{Entropy-based Cropping Strategy} (ECS) evaluates a small set of candidate crops and selects the one with minimal entropy, preserving contiguous regions relevant to the prompt. At training, \textbf{Entropy Regularization Training} (ERT) augments next-token prediction with an entropy term that sharpens attention on key visual tokens while down-weighting irrelevant ones. Experiments on ten VQA benchmarks show that ENCORE, fine-tuning only 0.14\% of parameters, achieves an average 1.43\% accuracy gain and state-of-the-art performance among recent 2B-parameter VLMs. Our code is released in https://github.com/baokou-fw2/ENCORE.

## 2. 提出的方法论

### 2.1 核心思想
- 以**跨模态注意力分布计算出的图像-文本熵**作为语义完整性的统一量化指标，分别用于**推理阶段的裁剪选择（ECS）**和**训练阶段的注意力锐化正则项（ERT）**。

### 2.2 关键技术细节

**（1）图像-文本熵（HS）定义**

从 VLM 第 k 层提取图像 token ZI 和文本 token ZT 后，对每个图像 token 定义 prompt 相关的注意力概率：

- 首选计算每个视觉 token 与所有文本 token 的相似度均值（经温度 τ 缩放后的 softmax）：

\[
p(Z_i^I | Z^T) = \frac{\exp\left(\frac{1}{M}\sum_{j=1}^{M} Z_i^I \cdot (Z_j^T)^T / \tau\right)}{\sum_{k=1}^{N}\exp\left(\frac{1}{M}\sum_{j=1}^{M} Z_k^I \cdot (Z_j^T)^T / \tau\right)}
\]

- 然后对该分布计算熵（ε 为避免零的对数，取 1e-32）：

\[
H_S = -\sum_{i=1}^{N} p(Z_i^I | Z^T) \log\left(p(Z_i^I | Z^T) + \varepsilon\right)
\]

**（2）ECS：Entropy-Based Cropping Strategy（推理阶段）**

- 从 VLM 前 k 层（实验取 k=1）计算不同候选裁剪比例（宽高比 1:1 ~ 4:1）下的 HS，**选择熵最小的裁剪比例**；
- 将该裁剪结果与原始图像整合后输入模型，以保留连续的 prompt 相关语义区域；
- 假设 prompt 相关区域在图中独立或分布多处时，熵仍能反映候选范围内的完整性，因此具备理论依据。

**（3）ERT：Entropy Regularization Training（训练阶段）**

在标准 next-token prediction 损失基础上加入熵正则项：

\[
\mathcal{L} = -\sum_{\ell=1}^{L} \log p(y_\ell | y_{<\ell}, x_{\le\ell}) + \alpha H_S
\]

- 对 prompt 相关 token（pi > 1/e），最小化 HS 强化其概率，与交叉熵目标一致；
- 对无关 token（pi < 1/e），自信息项抑制噪声配对，类似对比学习中的负采样效果；
- 从而**锐化模型对关键视觉 token 的注意力**，降低无关 token 的干扰。

### 2.3 关键超参数
| 参数 | 取值 | 含义 |
|------|------|------|
| k（ECS 层） | 1 | 计算熵所用的 VLM 层 |
| k（ERT 层） | 2 | 计算熵所用的 VLM 层 |
| τ（ECS） | 1 | 温度系数 |
| τ（ERT） | 0.1 | 温度系数（小温度锐化分布） |
| α | 0.1 | 熵正则项权重 |
| 裁剪范围 | 1:1 ~ 4:1（6 patches 上限） | ECS 候选宽高比 |

## 6. 主要结论与发现

- 早期层图像-文本熵是**可靠的语义完整性指标**；熵越低，prompt 相关区域的覆盖率和 VQA 准确率越高。
- ECS 通过选择最小熵裁剪可保留 prompt 相关区域的连续性，在复杂视觉语义任务（如 SEED-2、RWQA）上优于 MSAC 等纯视觉裁剪方法。
- ERT 通过熵正则项锐化关键视觉 token 的注意力（对 prompt 相关 token 强化、无关 token 抑制），改善了模型对碎片化高分辨率输入的感知能力。
- **综合性能**：仅微调 0.14% 参数，在 10 个 VQA 基准上平均准确率提升 1.43%，超越所有 2B 参数对比模型，达到 SOTA（如 TextVQA 79.8、OCRBench 845、MMStar 61.1 等）。
- 最佳实践：冻结后续层，初始层应用 ERT 最优；温度 τ 在 ECS 中取 1、ERT 中取 0.1 效果最佳。

## 7. 优点

- **方法轻量且高效**：仅 LoRA 微调 0.14% 参数，推理端 FLOPs 仅增加 7.2%、延迟增加 10%，非常契合轻量级 VLM 的应用场景。
