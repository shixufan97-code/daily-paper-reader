## 摘要
预训练的视觉-语言模型（如CLIP）在零样本识别方面表现出色，但在组合性方面经常失败，尤其是属性-对象和关系结构。近期研究通过级联大型语言模型和文本到图像模型生成的合成硬负样本增强训练来缓解这一问题，但这带来了相当大的流水线开销。我们转而提出MLLMCLIP，一种异构蒸馏框架，直接将多模态知识从生成式多模态大语言模型（MLLM）教师转移到判别式CLIP学生，完全绕过了合成数据。为弥合两种范式之间的架构不匹配，我们引入了基于注意力的逐层令牌选择和基于CKA的蒸馏损失。与先前的CLIP增强方法相比，MLLMCLIP在组合准确性上达到了最先进的水平，同时在标准零样本分类和图像-文本检索上取得了持续提升，表明特征级蒸馏同时增强了组合性和通用视觉-语言表示能力。

## Abstract
Pretrained vision-language models such as CLIP excel at zero-shot recognition but often fail at compositionality, particularly attribute-object and relational structures. Recent studies mitigate this issue by augmenting training with synthetic hard negatives generated by a cascade of large language models and text-to-image models, which incurs substantial pipeline overhead. We instead propose MLLMCLIP, a heterogeneous distillation framework that transfers multimodal knowledge directly from a generative Multimodal Large Language Model (MLLM) teacher into a discriminative CLIP student, bypassing synthetic data entirely. To bridge the architectural mismatch between the two paradigms, we introduce an attention-based per-layer token selection and a CKA-based distillation loss. Compared to prior CLIP-enhancement methods, MLLMCLIP achieves state-of-the-art compositional accuracy while delivering consistent gains on standard zero-shot classification and image-text retrieval, showing that feature-level distillation strengthens both compositional and general vision-language representation capability.

## 1. 核心问题与整体含义（研究动机与背景）

- 尽管 CLIP 等预训练视觉-语言模型在零样本分类与图文检索上表现优异，但其在**组合性理解**（compositionality）上存在明显缺陷，常表现为“词袋”行为，难以正确处理属性-对象、关系、空间排列等结构。
- 已有补救方案通常采用“**数据级蒸馏**”范式：借助 LLM 生成硬负样本文本，再利用文生图模型生成对应的负样本图像，以扩充训练集。其问题包括：
  - 依赖多个独立专家模型，缺乏统一的多模态理解；
  - 数据生成流水线冗长、迭代采样与质量筛选开销大；
  - 训练时需要额外编码大量合成负样本，效率低。
- 本文提出 **MLLMCLIP**，将范式从“数据级蒸馏”转向“**特征级蒸馏**”：直接从一个生成式多模态大语言模型（MLLM）教师中提取隐藏状态，蒸馏到判别式 CLIP 学生，**完全绕开合成数据生成**。
- 核心意义在于：验证了特征级蒸馏不仅提升组合性，还能同步增强通用零样本分类与图文检索能力，为轻量级视觉-语言编码器的构建提供了新路径。

## 2. 方法论

### 2.1 核心思想
- 使用一个冻结的 MLLM 作为教师，一个从零训练的 CLIP 双编码器（图像 + 文本）作为学生。
- 将教师的逐层隐藏状态与学生的逐层表示对齐，并同时保留 CLIP 原有的对比学习目标。

### 2.2 架构设计
- **学生端（CLIP）**：
  - 图像编码器与文本编码器分别产生逐层隐藏状态；
  - 每层隐藏状态经辅助层（Aux）投影到统一维度 D；
  - 最后一层特征经投影头用于对比学习。
- **教师端（MLLM）**：
  - 图像经 MLLM 视觉编码器，文本经模板包装后与图像特征拼接为统一序列，送入解码器；
  - 从每个解码器层提取隐藏状态。

### 2.3 跨架构对齐的关键技术
- **注意力驱动的 token 选择**：
  - 针对教师每一层，平均所有注意力头得到注意力矩阵；
  - 计算每个 token 作为 key 接收到的最大注意力；
  - 选择每一层中“被关注最多”的 token 作为该层代表教师特征；
  - 优点：自适应定位富含多模态信息的 token，优于固定位置（如图像结束符、文本结束符）。
- **逐层选择**：
  - 从教师全部层中以**均匀步长**抽取与学生对等数量的层进行蒸馏，优于只取某一连续块（低/中/高层）。
- **蒸馏损失（CKA 损失）**：
  - 采用 Centered Kernel Alignment（CKA）衡量学生与教师表示之间的结构相似度；
  - 先对特征矩阵中心化，计算 Gram 矩阵，再用归一化 Frobenius 内积求相似度；
  - 最终损失形式为 \( \ell = 1 - \sqrt{\text{CKA}(X_l, Y_{s_l})} \)；
  - 相比 MSE（直接对齐）或余弦/KL/JS 等逐样本对齐，CKA 在异构架构下效果最好，能保持样本间结构关系。
- **总损失**：\( \mathcal{L}_{total} = \mathcal{L}_{contrast} + \lambda \mathcal{L}_{distill} \)。
- 教师特征提取使用“组合性提示模板”（例如要求模型对比正确/错误描述、关注属性/动作/关系/空间），比纯 caption 提示带来一致的小幅提升。

## 3. 实验设计

- **预训练数据**：CC3M（Conceptual Captions）。
- **训练方式**：CLIP 学生从零训练（ViT-B/32 图像编码器 + 12 层 Transformer 文本编码器），而非从预训练 CLIP 微调；教师 MLLM 冻结。
- **教师模型**：涵盖 LLaVA-1.6-Mistral-7B、Qwen3-VL-2B、Qwen3.5-2B、InternVL3-2B、InternVL3.5-2B 等 5 种，验证教师无关性。
- **评测数据集**：
  - 组合性 11 个：ARO、CREPE、EQBEN、ImageCoDE、SugarCrepe、SVO-Probes、VALSE、VL-Checklist、WhatsUp、Winoground、SPEC；
  - 零样本分类 13 个：Caltech101、CIFAR-10/100、DTD、EuroSAT、FER2013、Flower102、Food101、ImageNet、KITTI、Pet、RESISC45、VOC2007；
  - 图文检索 2 个：MSCOCO 与 Flickr-30K（双向检索，R@1/5/10）。
- **对比方法**：
  - 数据级蒸馏方法：LaCLIP（LLM 重写正样本）、NegCLIP（LLM 硬负文本）、FSC-CLIP（WordNet/LLM 硬负）、TripletCLIP（LLM + SDXL-Turbo 生成负图像）；
  - MLLM 嵌入模型：VLM2Vec-v1/v2、Qwen3-VL-Embedding；
  - 对照组：使用相同 MLLM 分别提供数据级与特征级监督，排除教师身份差异。

## 4. 资源与算力

- 论文明确说明：
  - 训练硬件：**8 张 NVIDIA A100 GPU**；
  - 优化器 AdamW，全局 batch size 4096；
  - 训练 30 个 epoch，学习率 5×10⁻⁴，权重衰减 0.5，余弦退火 + 第一轮线性 warmup；
  - 使用 bfloat16 精度。
- 预处理效率比较中，单卡 batch size 32 下：
  - 数据级合成（文本生成 + 图像生成）平均耗时约 **0.835 s**；
  - MLLMCLIP 特征提取平均耗时约 **0.232 s**，约为前者的 1/3.6。
- 推理成本方面，MLLMCLIP（0.15B 参数，约 4.57 ms）相比 VLM2Vec-v2（2.22B，约 115.9 ms）快约 25 倍，比 Qwen3-VL-Embedding-2B（约 52.4 ms）快约 11 倍。

## 5. 实验数量与充分性

- **数量充足**：共 26 个评测基准（11 组合 + 13 分类 + 2 检索），外加 SugarCrepe 扩展细粒度评测（属性/物体/关系，替换/交换/添加等子任务）。
- **消融实验多样**：
  - token 选择策略（固定位置 vs 注意力选择；单 token vs 注意力加权池化 vs top-k 池化）；
  - 蒸馏损失函数（MSE、余弦、KL、JS、CKA）；
  - 教师层选择（低/中/高层块 vs 均匀步长）；
  - 教师提示（纯 caption vs 组合性提示）；
  - 蒸馏权重 λ（0.1/1/10/100）；
  - 数据级 vs 特征级监督（控制相同教师身份）；
  - 教师多样性（5 种不同 MLLM 教师）。
- **客观性与公平性**：
  - 基准实验全部在同等训练预算与数据规模下复现；
  - 消融中使用同一教师、同一种子设置，控制了教师身份、提示等混淆因素；
  - 对 MLLM 评测采用 QA 形式，并通过交换选项位置两次评估来规避位置偏差；
  - 数据级基线使用的外部模型往往更大（如 LLaMA-7B、Qwen3-4B、SDXL-Turbo），仍不及 MLLMCLIP，说明特征级蒸馏优势并非来自更大教师。

## 6. 主要结论与发现

- 当前 MLLM 具备较强的组合理解能力，但**经过 embedding 式微调的 MLLM 组合能力显著退化**，因此应蒸馏基础 MLLM 而非嵌入模型。
- MLLMCLIP 在组合性上超越所有数据级蒸馏方法，五种教师下均稳定优于 LaCLIP、NegCLIP、FSC-CLIP、TripletCLIP。
- 在零样本分类与图文检索上，MLLMCLIP 同样一致领先，说明组合性增强并未牺牲通用能力，反而互相促进。
- CKA 结构性对齐在多模态异构蒸馏中显著优于直接逐样本匹配（MSE 甚至导致崩溃）。
- 注意力引导的 token 选择优于固定位置 token，均匀跨层选择优于单一块层。
- 相比 MLLM 嵌入模型，MLLMCLIP 以极低的推理成本获得接近甚至更优的权衡。

## 7. 优点

- **范式创新**：从昂贵的合成数据流水线转向直接特征级蒸馏，大幅降低预处理与训练成本。
- **架构适配**：针对生成式解码器 → 判别式编码器的异构差异，设计了注意力 token 选择 + CKA 结构损失，而非简单照搬同构蒸馏。
- **教师无关**：在多种 MLLM 教师下表现一致，具备良好的泛化性。
- **全面评测**：同时覆盖组合性、零样本分类与检索，验证了通用表示能力的整体提升。
- **公平对比**：对基线在相同预算下复现，并额外控制教师身份，避免“教师更强”的归因干扰。
- **效率优势明显**：特征可离线预提取，预处理速度快约 3.6 倍，且支持更大 batch；推理时保持轻量 CLIP 双编码器。

## 8. 不足与局限

- **受教师能力上限约束**：教师 MLLM 的偏差或推理错误会迁移给学生，最佳教师可能因下游任务而异。
- **提示敏感性**：虽然论文验证了组合性提示带来的增益，但方法对提示模板的依赖未做系统消融，仍需进一步探索更优提示设计。
- **训练数据规模有限**：仅用 CC3M 从零预训练，未在更大数据集（如 LAION、DataComp）上进行验证，结论在更大规模下的普适性存疑。
- **单种子结果**：所有实验均为单次运行，缺少多次重复的方差统计，尽管在多个教师上趋势一致。
- **组合性评测的潜在偏置**：MLLM-as-judge 评测受选项顺序影响，论文通过两次交换位置缓解但未完全消除；一些基准（如 Winoground、ARO）单个任务仍较难突破。
- **教师多样性以“换模型”为主**：未深入分析不同模型规模（如 2B vs 4B/8B）对蒸馏效果的影响，仅在部分评测中出现较大教师模型的对比。
